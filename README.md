# Karate klub Sambon Vogošća

Statična web stranica za Karate klub Sambon, inspirisana premium sportskim stilom stranice The Performance Lab.

## Sadržaj

- početna hero sekcija
- programi: karate vrtić, škola karatea, takmičarski tim
- proces upisa i napretka
- trener/klub sekcija
- kontakt i poziv na upis

## Objavljivanje

Repo je spreman za GitHub Pages, Netlify ili Vercel.

Za GitHub Pages:

1. Otvori **Settings** u repozitoriju.
2. Idi na **Pages**.
3. Pod **Build and deployment** izaberi **Deploy from a branch**.
4. Branch: `main`, folder: `/root`.
5. Sačuvaj i sačekaj da GitHub generiše link.

## Fotografije

Trenutno su korištene zamjenske sportske fotografije. Za finalnu verziju najbolje je zamijeniti ih originalnim fotografijama Karate kluba Sambon sa treninga, takmičenja i dodjela medalja.

Glavne lokacije za zamjenu slika su u `index.html`:

- `.hero:before`
- `.coach-media`
- `.photo.one`
- `.photo.two`
