# Karate klub Sambon Vogošća

Web stranica kluba: fotografije i rezultati sa 17. Vogošća Opena, grupe i termini, put do crnog pojasa i prijava za prvi trening. Jedna statična `index.html` stranica.

Mjesta označena tačkastom crtom (termini, članarina, adresa sale, zahtjevi za pojaseve) čekaju potvrdu kluba.

Objava: Vercel (`vercel.json` kopira `index.html` u `public/`).
